# Static Variable in C++ Function

This repository contains a simple C++ program that demonstrates the use of a **static variable inside a function**. The program shows how the value of a static variable is preserved between multiple function calls.

## 📌 Program Highlights
- Demonstrates `static` keyword in C++
- Shows lifetime of static variables
- Beginner-friendly example
- Easy to understand output

## 🧠 Concepts Covered
- Static variables
- Function calls
- Variable lifetime and scope
- Basic C++ syntax
